# Unit Converter in C

A simple console-based Unit Converter written in C. This program allows users to convert values between different units of Length, Area, Volume, Mass, Velocity, Pressure, Energy, Power, and Temperature through an interactive menu-driven interface.

## Features

### Length Conversion
- Inch ↔ Centimeter
- Meter ↔ Foot
- Yard ↔ Meter
- Mile ↔ Kilometer
- Nautical Mile ↔ Meter

### Area Conversion
- Acre ↔ Square Meter

### Volume Conversion
- US Gallon ↔ Liter
- UK Gallon ↔ Liter

### Mass Conversion
- Ounce ↔ Gram
- Kilogram ↔ Pound

### Velocity Conversion
- Kilometer per Hour ↔ Meter per Second

### Pressure Conversion
- Atmosphere ↔ Pascal
- mmHg ↔ Pascal
- kgf/cm² ↔ Pascal
- lbf/in² ↔ kPa

### Energy Conversion
- kgf·m ↔ Joule
- Joule ↔ Calorie

### Power Conversion
- Horsepower ↔ Kilowatt

### Temperature Conversion
- Fahrenheit ↔ Celsius

---

## Technologies Used

- C Programming Language
- Standard Input/Output Library (`stdio.h`)

---

## How to Compile

Using GCC:

```bash
gcc main.c -o converter
```

---

## How to Run

```bash
./converter
```

---

## Example

```text
1. Length
2. Area
3. Volume
4. Mass
5. Velocity
6. Pressure
7. Energy
8. Power
9. Temperature
```

The user selects a category, chooses a conversion type, enters a value, and receives the converted result.
